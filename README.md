# formfeed/sdk

The PHP SDK for the [Formfeed](https://docs.formfeed.dev) API, which renders PDFs and images from
templates, HTML or URLs and works on existing PDFs.

**It is being written and has no release yet.** Until it has one, the API takes any HTTP client:
one `POST` with your API key renders a document, as the [documentation](https://docs.formfeed.dev)
shows. A Laravel package, `formfeed/laravel`, follows with the first release.

This repository is written by Formfeed's release process; changes made here are overwritten.
Questions go to support@formfeed.dev.
